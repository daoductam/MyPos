# Spec: Tạo Bộ Tài Liệu Kỹ Thuật (Technical Design Documents)

## Mục tiêu
Tạo folder `technical-docs/` tại root project chứa:
- `SRS.md` — Tài liệu Đặc tả Yêu cầu Phần mềm tổng thể
- 13 feature folders, mỗi folder chứa `README.md` là TDD (Technical Design Document) chi tiết

## Ngôn ngữ
Toàn bộ tiếng Việt

## Nguồn dữ liệu
