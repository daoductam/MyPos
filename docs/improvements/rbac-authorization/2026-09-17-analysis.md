## Approved Implementation Order

1. Create repository ports and JDBC adapters without changing permission or scope contracts.
2. Refactor snapshot and scope consumers, then admin/mutation/audit services.
3. Replace mutation audit string concatenation with `ObjectMapper` serialization.
4. Add focused unit tests and run backend/frontend regression checks.

## Items Deferred

- Redis key invalidation optimization using `SCAN` instead of `KEYS`: important for large Redis deployments, but not required to remove SQL coupling and would change cache operational behavior.
- Full JPA replacement: intentionally out of scope; RBAC repositories may continue using `JdbcTemplate`.
- Production MySQL/Flyway rehearsal: requires a configured MySQL environment and is a deployment gate rather than a local refactor test.
